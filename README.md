# Python3 エンジニア認定基礎試験 対策Webアプリ

Python3エンジニア認定基礎試験の学習用Webクイズアプリです。  
全400問の問題バンクを使い、スマートフォンからでも繰り返し学習できます。

## デモ

🔗 https://python3-exam-app.streamlit.app

※デモの利用には合言葉が必要です。（合言葉：python2026）

## 主な機能

| 機能 | 概要 |
|------|------|
| 4つの学習モード | 本番想定（40問/60分タイマー）・短時間（10問）・章指定・間違い再挑戦 |
| 選択肢のランダム生成 | 誤答プール6つから毎回3つを抽出し、正解と合わせてシャッフル |
| 採点・章別集計 | 正答率・合否判定（70%以上）に加え、章ごとの正答率を表示 |
| AIヒント | 問題文だけをChatGPTに送り、ヒントを得られるリンクボタン |
| 簡易認証 | 合言葉による認証。氏名はBase64でURLパラメータに保持し、リロード後もセッション維持 |

## 使用技術

- **Python 3** / **Streamlit**
- **Streamlit Community Cloud**（ホスティング）
- **Streamlit Secrets**（合言葉の管理）
- **JSON**（問題データ 400問）

## 開発上の工夫

- **ロジックとUIの分離** — 出題・採点ロジック（`quiz_engine.py`）と画面表示（`app.py`）を分離し、テスト・保守しやすい構造にした
- **CSSによるモバイル最適化** — Streamlit標準のレイアウトが狭い画面で崩れる問題を、`st.container(key=...)` が生成するCSSクラスを利用したFlexbox指定で解決
- **URLパラメータのエラー処理** — 不正なURLパラメータでもアプリがクラッシュしないよう、デコード処理を `try-except` で保護

## プロジェクト構成

```
python-exam-app/
├── data/
│   └── questions.json        # 問題データ（400問）
├── src/
│   ├── app.py                 # 画面表示・画面遷移（Streamlit）
│   ├── quiz_engine.py          # 出題・採点ロジック
│   └── utils.py                # 氏名のBase64エンコード/デコード

```
